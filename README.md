# Sezginler Solar Enerji - Web Sitesi

Kurumsal, premium, scroll tabanlı 3D animasyonlu GES web sitesi.

## Yapı
```
index.html
assets/
  css/style.css
  js/main.js      (Three.js 3D sahne, scroll animasyonları, WhatsApp formu)
  img/            (logo ve GES görselleri buraya)
```

## Çalıştırma
`index.html` dosyasını tarayıcıda açın (3D için internet bağlantısı gerekir, Three.js CDN'den yüklenir).
